# Phase 1 Engineering Handoff: Analytic Vector Pipeline, Generator Refactors & Export Upgrades

## Objective
Refactor the geometric pattern generator from a polyline-discretized, destructively post-processed renderer into an **analytic vector pipeline** that produces razor-sharp, Figma-ready editorial graphics. Every generator must output clean mathematical primitives, obey strict framing bounds, enforce single-concept archetype purity, and serialize into structured, low-anchor-count SVGs.

---

## 1. Core Architecture & Pipeline Upgrades

### 1.1 Analytic Scene IR & Cubic Bézier Serialization (`scene.js`, `svg-writer.js`)
Stop discretizing smooth curves into dense polylines before finishing/export. Preserve analytic geometry through the entire Scene IR:
- **Native Primitives:** Emit exact `<circle>`, `<ellipse>`, and elliptical arc `<path d="M ... A rx ry rot largeArc sweep x y">` elements for all circular/elliptical geometry.
- **Error-Bounded Bézier Fitting:** For non-analytic curves (3D projections, logarithmic spirals, field streamlines), fit piecewise cubic Béziers (`C`) using Schneider's chord-length parameterization with max deviation `ε = 0.15px`.
- **Semantic Path Metadata:** Attach the following metadata to every IR node:
  ```js
  {
    role: 'primary' | 'secondary' | 'guide' | 'node' | 'annotation',
    visibility: 'front' | 'back' | 'full', // 'back' serializes with stroke-dasharray="2 5"
    taper: null | {
      startSolidRatio: 0.65,
      endDotSpacing: 6,
      terminalNodeRadius: 4.5
    },
    zPriority: 0 // integer 0..10; higher priority punches knockouts into lower priority
  }
  ```

### 1.2 Two-Stage Canonical Framing Transform (`scene.js`)
Decouple pattern geometry from `1000×1000` viewport placement. Every generator must construct geometry in canonical coordinates centered at `(0, 0)` and return two explicit bounding boxes: `coreBounds` (the focal structure) and `bleedBounds` (outer boundary orbits/arcs allowed to cross the frame edge).
- **`CENTERED EMBLEM` Mode:** Compute uniform scale `s = 740 / max(coreBounds.width, coreBounds.height)` and translate the centroid to `(500, 500)` so every centered composition fills ~74% of the canvas.
- **`OFF-AXIS FOCAL` Mode:** Scale `coreBounds` to 55%–65% of the viewport (`550–650px`), then translate the focal centroid by `(Δx, Δy)` clamped strictly to `[-110, 110]` around `(500, 500)`. Only `bleedBounds` may cross the `[0, 1000]` viewport edges; `coreBounds` must never clip off-canvas.

### 1.3 Analytic Intersection Knockouts (`finish-pipeline.js`)
- **Remove Destructive Post-Processing:** Delete the offset duplicate "ghost stroke" in the roughness pass and disable random mid-curve chunk deletion (`lineBreaks`).
- **Geometric Bridge Solver:** Replace random line breaks with intentional negative-space crossings:
  1. Spatial-hash all paths into a `20×20` grid (`50px` cells) for fast candidate lookup.
  2. Compute exact intersection parameters `(tA, tB)` between foreground paths (`zPriority >= 7`) and background paths (`zPriority < 7`).
  3. Split the background path at `tB ± Δt` corresponding to an arc-length gap of `±6px`.
- **Primitive Promotion Edge Case:** When a `<circle>` or `<ellipse>` is punched by a knockout, promote **only that intersected primitive** to an elliptical arc `<path>` (`A` command) at serialization time. Keep all un-intersected circles/ellipses as native primitives.
- **60fps Scrubbing Performance:** Skip the intersection bridge solver during active slider drag (`pointermove`). Run it on `pointerup` (or debounced by ~60ms) and always run it on SVG copy/export.

### 1.4 Archetype-Locked Parameter Profiles (`taste-profile.js`, `scene.js`)
- **Clean Vector Defaults:** Set default sampled `roughness = 0.0`, `lineBreaks = 0.0`, and `overshoot = 0.0` across all presets in `taste-profile.js` so `Next Pattern` never injects accidental sketch wobble or broken segments. Keep those parameters functional only when manually adjusted by the user.
- **Remove Forced Bullseye Injection:** Strip automatic center bullseye dots out of `Scene.enforceAtomHint()`. Only render a central nucleus dot when explicitly defined by the archetype's math (e.g., Keplerian shared focus, radial burst origin, or rosette center)—never inside hollow 3D wireframes or golden spirals.

## 2. Generator-Level Mathematical Refactors

Enforce **single-concept archetype purity** in every generator—never mix unrelated motifs in the same render.

- **`lobes.js` & `field-lines.js` (Optical Caustic Density):**
  - Use non-linear parameter easing `u_i = sin²((π * i) / (2 * N))` with `N ∈ [32, 64]` so curves compress into crisp caustic ridges and open into clean negative space.
  - Remove the tilted 3D wireframe bounding box and edge ticks from `field-lines.js` so streamlines float cleanly on the canvas.
- **`wireframes.js` (3D Sphere, Torus & Hyperboloid):**
  - Project 3D latitude/longitude rings and torus cross-sections analytically onto 2D ellipses (`12–24` rings).
  - Split each projected ellipse at its horizon tangency points into `visibility: 'front'` (solid `1.0px`) and `visibility: 'back'` (dotted `2 5`, `0.8px`), framed by a single solid outer horizon silhouette (`1.6px`).
  - Suppress diagonal tick-marked skewer axes and center dots unless `Annotation Artifacts` is explicitly toggled `ON`.
- **`orbit-system.js` (3 Distinct Sub-Archetypes):**
  - *Mode 1 — Keplerian Plate:* `8–14` ultra-fine (`0.7px`) closed ellipses computed via polar conic equations `r(θ) = a(1 - e²) / (1 + e * cos(θ - ω))` sharing one exact focus dot, nested inside a circular boundary with `3–4` concentric inner rings.
  - *Mode 2 — Graphic Orbital Emblem:* Central sphere (solid outer circle + solid front equator + dotted back equator) orbited by `3` tilted open arcs using `taper` metadata (solid arc → dotted tail → bold terminal solid dot) with minimal open chevron arrowheads (`>`).
  - *Mode 3 — Sweeping Trajectory Study:* `2–3` opposing sweeping S-curved/elliptical arcs with open chevrons, `2–3` parallel motion-trail hairlines around a tight tilted inner core, and `4–6` hollow marker rings (`r = 4px`) placed via Poisson-disc sampling in outer negative space.
- **`tangent-chain.js` & `spirals.js` (Motif Separation):**
  - Never combine rotated polygon spirals with tangent circle chains in one output.
  - *Mode 1 — Eccentric Tangent/Secant Circles:* `6–9` clean circles of varying radii mutually tangent or secant inside an oversized outer circle (`bleedBounds`) that sweeps past the frame edge, with crisp nodes at exact tangency points and zero straight lines.
  - *Mode 2 — Full-Scale Whirling Square / Golden Construction:* Scale construction geometry via `coreBounds` to fill ~75% of the canvas, extend construction diagonals cleanly to the enclosing arc/circle, and remove all random gaps and floating bullseye dots.
- **`rosette.js` (Exact Tangency & Lattices):**
  - For concentric circle rings, solve exact non-overlapping radii `r = R_ring * sin(π / N)` so adjacent circles touch with zero overlap and zero gap. Place vertex nodes or concave stars deterministically at 100% (or alternating 50%) of tangent cusps—never randomly.
  - Add a **3×3 Overlapping Circle Lattice (Seed-of-Life)** mode with uniform intersection dots and one subtle highlighted crescent arc.
- **`particle-burst.js` (Full-360° Stratified Radial Field):**
  - Replace clumped wedges with `32–48` rays distributed across `0..2π` using stratified jitter: `θ_i = (2π * i / N) + δ_i`, where `|δ_i| < 0.35π / N`.
  - Modulate ray lengths smoothly within `[0.35R, 0.92R]` (`R` filling ~80% of canvas radius) and render an open chevron arrowhead at every ray tip. Hide outer calibrated ruler rings unless `Annotations` is `ON`.

## 3. UI & Workflow Upgrades

- **Seed History & Pin Strip:** Maintain a back/forward history stack (last 25 seeds/states) plus a one-click star/pin bar so users never lose a strong output when clicking *Next Pattern*.
- **Per-Slider Lock Toggles:** Add a small lock icon next to each parameter slider so *Next Pattern* only randomizes unlocked controls.
- **Sub-Archetype Selector:** Expose a compact segmented pill selector for generators with multiple distinct modes (e.g., `Orbit Systems`: *Keplerian* | *Emblem* | *Trajectory*; `Tangent Chains`: *Circle Packing* | *Golden Construction*; `Rosettes`: *Tangent Rings* | *3×3 Lattice*).
- **Canvas Preview Toggles:** Add a toolbar toggle for **Dark / Light / Transparent** preview backgrounds and a non-exporting **Safe-Margin & Center Crosshair** overlay.
- **Collapsible "Organic / Sketch" Drawer:** Keep `Roughness`, `Line Breaks`, and `Overshoot` defaulted to `0.0` and move them into a collapsed *Texture & Imperfection* accordion so primary controls stay focused on geometry, density, and stroke weight.

---

## 4. Export & Figma-Readiness Upgrades

- **One-Click "Copy SVG" Action:** Add a button that copies the serialized `<svg>` markup directly to the clipboard (`navigator.clipboard.writeText`) for instant `Cmd+V` pasting into Figma/Illustrator.
- **Semantic SVG Layer Groups:** Group exported elements cleanly by IR metadata rather than a flat list:
  - `<g id="primary-structure">`
  - `<g id="secondary-detail">`
  - `<g id="back-faces-dotted">`
  - `<g id="nodes-and-markers">`
  - `<g id="annotations">` (omitted if empty)
- **Re-Importable SVG State Metadata:** Embed `<metadata data-atom-state='{"generator":"...","subMode":"...","seed":12345,"params":{...}}' />` in every exported SVG, and support dragging any exported SVG back onto the app window to restore its exact state.
- **Coordinate Precision & Stroke Scaling:** Round all numeric SVG coordinates/attributes to 2 decimal places (`toFixed(2)`), and provide an export toggle between **Fixed Stroke** (default for Figma/print) and `vector-effect="non-scaling-stroke"` (for responsive web embeds).

---

## 5. Verification & Acceptance Criteria

Before concluding Phase 1, add a small CLI script (`npm run qa:samples`) that generates 2 fixed seeds per generator/sub-mode and logs a structural report verifying:
1. **Low Anchor Counts:** Typical outputs contain `< 400` total vector anchors (down from 4,000–14,000), with native `<circle>`/`<ellipse>` elements preserved wherever un-intersected.
2. **Zero Core Clipping:** Every `coreBounds` rectangle lies strictly inside `[0, 1000] × [0, 1000]` in both `CENTERED EMBLEM` and `OFF-AXIS FOCAL` modes.
3. **Clean Default Finish:** Default seeds run with `roughness === 0`, `lineBreaks === 0`, zero ghost duplicate paths, and clean `±6px` intersection knockouts where foreground curves cross background curves.
4. **Figma Round-Trip:** Exported SVGs parse cleanly, contain semantic `<g>` layers, round all coordinates to 2 decimal places, and restore state accurately when dropped back into the app.
